DP 문제가 그렇듯이 DP의 차원값을 선택하는 게 제일 어렵다.

처음에는 i, j, prev 값만 저장하면 될 거라고 생각했는데,

cnt 값도 저장해야 하는 이유는 현재 위치와 마지막으로 방문한 오락실 번호가 같더라도, 앞으로 방문해야 하는 오락실의 개수에 따라 가능한 경로의 수가 달라지기 때문이다.

예를 들어 i, j, prev가 같더라도 cnt=1이면 오락실을 정확히 1개 더 방문해야 하고, cnt=2이면 정확히 2개를 더 방문해야 한다. 따라서 두 상태는 서로 다른 결과를 반환할 수 있으므로 별도로 저장해야 한다.

결국 DP의 차원은 단순히 현재 위치를 나타내는 값이 아니라, 이후의 결과를 결정하는 데 필요한 모든 상태를 포함해야 한다는 것을 배웠다.
