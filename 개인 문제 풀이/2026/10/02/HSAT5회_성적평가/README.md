N이 10만이기 때문에 각 idx마다 몇등인지 알려고 벡터를 매번 조회하면 100억번 연산하기 때문에 이 개념을 알고 풀어야함

2중 for문을 피하는 방식으로 시험별 등수를 파악하고 이를 다시 idx 순으로 정렬하므로 2번의 정렬이 필요하다

```cpp
  sort(tmp.begin(), tmp.begin()+n, [](auto& a, auto& b){
      return a[1] < b[1];
  }); //idx 오름차순
```

이런 문제는 입력 예제를 태블릿에 그려가면서 이차원 벡터에 어떤식으로 저장해나갈지 순차적으로 생각해나가야 한다
