입력 string vector 를 파싱하는 `문자열` 문제이다

현재 헤더 영역인지는 처음으로 int가 들어올때까지, 

현재 number 영역 인지는 헤더영역이 아닌데 숫자가 들어오지 않을때까지 로 판단한다

tail값은 버린다

그후 문제가 정의한 기준에 의해 커스텀 비교자 함수로 정렬하고 그 정렬된 인덱스에 맞게 정답 벡터에 넣어주면 된다

풀고 지피티랑 얘기해보니까 char가 0인지에 대한 판단은 아스키로 보는거 보다 그냥 바로 문자열로 가능하다고 한다 

내가 짠 코드는 
```cpp
bool is_int = (int(files[i][ii]) <= 57 && int(files[i][ii] >=48));
```

지피티가 추천한 코드는

```cpp
bool is_int =
    (files[i][ii] >= '0' && files[i][ii] <= '9');
```
