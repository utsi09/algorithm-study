처음엔 visited[]로 물건 선택 여부를 관리했는데, dp[bag]만으로는 어떤 물건이 남았는지 알 수 없어서 문제였음.

dp[idx][bag]로 바꿔서 현재 인덱스와 배낭 무게를 기준으로 메모이제이션.

idx를 계속 증가시키니까 visited[] 없이도 중복 선택 방지 가능.

같은 idx, bag에 도달했다면 이전에 뭘 담았든 앞으로 선택할 수 있는 물건과 남은 무게가 같으므로 최대 추가 가치도 같음.

현재 물건을 담거나 안 담는 두 경우를 재귀로 탐색하고 최댓값 저장.

처음엔 for문과 미선택 재귀를 같이 썼는데 불필요한 중복 탐색이 있어서 for문 제거.

시간 복잡도: O(NK)
