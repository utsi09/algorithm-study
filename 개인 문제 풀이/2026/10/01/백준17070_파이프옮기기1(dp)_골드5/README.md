처음에는 최단거리를 푸는 방식으로 잘못 풀었는데 모든 경우의 수를 구하는 방식으로 코드를 바꿨다

차이는 최단거리는 목적지 도착하면 0을 리턴을 하면서 그동안 재귀함수로 solve를 부르면서 동시에 1을 더해 갔던거를 거리로 계산하는 방식이고

갈 수 있는 모든 경우의 수는 here을 0으로 초기화하고 solve에서 되돌아온 값을 here에 더하는 것이다

가로에서 세로로, 세로에서 가로로, 즉 2번을 회전하는 경우를 막는 코드는

```cpp
if(abs(state - d) > 1){ //2번회전 불가능
            continue;
        }
```
